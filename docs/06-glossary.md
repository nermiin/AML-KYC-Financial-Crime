# Glossary — AML/KYC

| Term | Definition |
|------|------------|
| **CDD** | Customer Due Diligence — identity verification and risk assessment |
| **EDD** | Enhanced Due Diligence — additional scrutiny for higher-risk customers |
| **PEP** | Politically Exposed Person |
| **RCA** | Relative or Close Associate of a PEP |
| **SAR / STR** | Suspicious Activity/Transaction Report filed with FIU |
| **MLRO** | Money Laundering Reporting Officer |
| **TM** | Transaction Monitoring |
| **FIU** | Financial Intelligence Unit |
| **ID&V** | Identity and Verification (document + biometric) |
| **Adverse Media** | Negative news screening for financial crime relevance |
| **Straight-Through Processing** | Automated approval without manual touch |
